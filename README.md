# Daily Buzz

A static demo news website built with plain HTML, CSS, and a touch of vanilla JavaScript. No build step, no dependencies — just open it in a browser.

## Pages

| File                 | Description                                               |
| -------------------- | --------------------------------------------------------- |
| `index.html`         | Homepage — featured story plus section teasers            |
| `world.html`         | World section — global news & good-news stories           |
| `people.html`        | People section — profiles, including the featured ranking |
| `culture.html`       | Culture section — film, music, gaming, internet trends    |
| `business.html`      | Business section — startups, markets, workplace trends    |
| `opinion.html`       | Opinion section — commentary and essays                   |
| `article-top10.html` | Full article: "Top 10 Influential Somali Ladies"          |
| `styles.css`         | Shared stylesheet used by every page                      |

## Structure & Design

- **Shared stylesheet** (`styles.css`) keeps the masthead, navigation, typography, and card layouts consistent across all pages.
- **Navigation bar** is identical on every page, with the current section highlighted.
- **Responsive layout** — section grids collapse to a single column and type scales down on narrow (mobile) viewports.
- **Dynamic date** — the date shown in the masthead is generated by JavaScript on page load (`new Date()`), so it always reflects the visitor's current date rather than a hardcoded value.

## Running Locally

No server or build tools required. Either:

1. Double-click `index.html` to open it directly in a browser, or
2. Serve the folder locally for a more realistic experience:
   ```bash
   python3 -m http.server 8000
   ```
   then visit `http://localhost:8000`.

## Customizing

- **Add a new article:** copy `article-top10.html`, replace the headline/body content, and link to it from the relevant section page's `feature-card` or `story-card`.
- **Add a new section:** duplicate one of the section pages, update the nav `active` link, and add the new page to the `<nav>` list across all other pages.
- **Colors & fonts:** controlled via CSS custom properties at the top of `styles.css` (`--paper`, `--ink`, `--saffron`, `--teal`, etc.) and the Google Fonts import (Fraunces + Source Sans 3).

## Note

This is a fictional demo publication built for illustrative/design purposes. Headlines, bylines, and most named individuals (aside from where explicitly specified) are invented and do not describe real people or events.
